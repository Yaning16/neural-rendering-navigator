# Neural Rendering Research Navigator

An interactive learning guide for beginners exploring neural rendering: pick a plain-language goal, follow a learning path of concepts and papers, check your understanding, and experiment in the Volume Rendering Lab. Available in English and 简体中文.

**Try it:** https://yaning16.github.io/neural-rendering-navigator/

This repository contains only the built website. Explanations marked "Draft" were drafted with AI assistance and have not yet been checked against their sources. Feedback is welcome.
